# Moving Pink Ball with Sparks 

An interactive GUI application written in Java Swing featuring a controllable pink ball with dynamic spark particle effects.

## Features
- *Keyboard Controls:* Move the ball using arrow keys (Up, Down, Left, Right).
- *Custom Animation:* Dynamic spark/particle simulation around the main ball.
- *Smooth Rendering:* Uses 2D Graphics rendering with anti-aliasing.

## Requirements
- Java Development Kit (JDK) 11 or higher.
- IDE (Eclipse, VS Code, or IntelliJ) or Terminal.
